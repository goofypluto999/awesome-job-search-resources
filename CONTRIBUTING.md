# Contributing to Awesome Job Search Resources

Thank you for your interest in contributing! This document provides guidelines for contributing to this repository.

## How to Contribute

### 1. Fork the Repository
- Click the "Fork" button on the repository page
- Clone your fork locally

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes
- Add new resources
- Fix typos or broken links
- Improve existing content
- Update documentation

### 4. Commit Your Changes
```bash
git commit -m "Add: description of your changes"
```

### 5. Push and Create Pull Request
```bash
git push origin feature/your-feature-name
```

## Content Guidelines

### What to Add
- ✅ Free resources
- ✅ High-quality content
- ✅ Recently updated resources
- ✅ Diverse perspectives
- ✅ Beginner-friendly content

### What NOT to Add
- ❌ Paid courses (unless they're exceptional)
- ❌ Outdated information
- ❌ Broken links
- ❌ Duplicate content
- ❌ Spam or promotional content

## Formatting Guidelines

### Links
- Use descriptive link text
- Include a brief description
- Check that links work

### Categories
- Keep categories logical and organized
- Use consistent naming conventions
- Add new categories when needed

## Review Process

1. All submissions will be reviewed
2. We may suggest improvements
3. Please respond to feedback promptly
4. Maintain a friendly and respectful tone

## Questions?

Feel free to open an issue if you have questions about contributing!
